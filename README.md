# tool-mc-plugin

자동화, 플러그인, 스킬을 모아 두는 저장소입니다.

| 항목 | 내용 |
|---|---|
| 유형 | Tool (자동화 / 플러그인 / 스킬) |
| 공개 범위 | Public |
| 라이선스 | MIT |

## 폴더 구성

작업이 쌓이면 아래 구조를 기준으로 정리합니다.

```
tool-mc-plugin/
├─ README.md          저장소 소개 (이 파일)
├─ CLAUDE.md          Claude Code 작업 지침
├─ .env.example       환경변수 견본 (실제 값 금지)
├─ .gitignore         업로드 제외 목록
└─ <스킬 또는 플러그인 이름>/
   ├─ README.md       용도, 설치법, 필요한 환경변수
   └─ ...
```

## 사용 시 주의

- 실제 키와 토큰은 저장소에 두지 않고 각자 PC의 환경변수로 설정합니다.
- 필요한 환경변수는 `.env.example`과 각 폴더의 README에서 확인합니다.
- 보안 규칙과 작업 규칙은 `CLAUDE.md`를 참고하세요.
